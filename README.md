# Ricochet Robots

A Java desktop implementation of the Ricochet Robots board game, developed as a group coursework project. The repository preserves several project iterations and the final source tree.

## Explore the code

- `Ricochet Robots/src/controller/`: application entry point, bidding, settings, timing, and saved-game support.
- `Ricochet Robots/src/view/`: game board, menus, robots, tokens, and other interface components.
- `Group-3-Iteration-*`: historical iteration material.

## Open the project

Use a Java IDE with a JDK installed. Import the source under `Ricochet Robots/src` and use `controller.Driver` as the main class. Preserve the project’s resource layout and inspect image/resource paths when choosing the working directory.

There is no Maven or Gradle build at the repository root. Compatibility with a current JDK has not been verified in this documentation pass.
